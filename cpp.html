01 • C++ NIMA?

C++ haqida

C++ — kuchli va tez ishlaydigan umumiy maqsadli dasturlash tili.

03 • VARIABLES

O‘zgaruvchilar

C++ o‘zgaruvchilarda ma'lumot turini aniq ko‘rsatishni talab qiladi.

Masalan: int — butun son, double — kasr son, string — matn, bool — mantiqiy qiymat.

variables.cpp 
#include <iostream>
#include <string>

using namespace std;

int main() {

    string name = "Coder";
    int age = 12;
    double score = 95.5;
    bool active = true;

    cout << name << endl;
    cout << age << endl;
    cout << score << endl;
    cout << active << endl;

    return 0;
}

C++ dasturiga shart asosida qaror qabul qildirish mumkin.

    int age = 18;

    if (age >= 18) {

        cout << "Kirish mumkin";

    } else {

        cout << "Kirish mumkin emas";

    }

    return 0;
}

09 • POINTERS

Pointerlar

C++ning kuchli tomonlaridan biri — xotira bilan bevosita ishlash imkoniyati. Pointer o‘zgaruvchining xotiradagi manzilini saqlashi mumkin.

pointer.cpp 
#include <iostream>

using namespace std;

int main() {

    int number = 50;

    int* pointer = &number;

    cout << "Qiymat: "
         << *pointer
         << endl;

    return 0;
}

11 • CLASS & OBJECT

Birinchi Class

user.cpp 
#include <iostream>

using namespace std;

class User {

public:

    string name;
    int age;

    void showInfo() {

        cout << "Ism: "
             << name
             << endl;

        cout << "Yosh: "
             << age
             << endl;

    }
};

int main() {

    User user;

    user.name = "Coder";
    user.age = 12;

    user.showInfo();

    return 0;
}
