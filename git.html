01 • GIT NIMA?

Git haqida

Git — fayllardagi o‘zgarishlarni kuzatib boruvchi versiyalarni boshqarish tizimi.

Masalan, loyihangizning bugungi holatini saqlab qo‘yishingiz va keyin biror xato chiqsa oldingi holatga qaytishingiz mumkin.

Git dasturchilarga katta loyihalarni xavfsizroq boshqarish va boshqa dasturchilar bilan hamkorlik qilish imkonini beradi.

04 • BASIC COMMANDS

08 • GITHUB

GitHub nima?

GitHub — Git repositorylarini internetda saqlash va ular bilan ishlash uchun keng ishlatiladigan platforma.

GitHub orqali loyihani boshqalar bilan ulashish, kodni ko‘rib chiqish va jamoa bo‘lib ishlash mumkin.

09 • REMOTE

GitHub repositoryga ulanish

Terminal 
git remote add origin https://github.com/USERNAME/PROJECT.git

git branch -M main

git push -u origin main
10 • CLONE

Tayyor loyihani yuklab olish

Terminal 
git clone https://github.com/USERNAME/PROJECT.git

cd PROJECT
11 • PULL

Yangilanishlarni olish

Terminal 
git pull origin main
12 • PUSH

Kodni GitHub'ga yuborish

Terminal

git push
