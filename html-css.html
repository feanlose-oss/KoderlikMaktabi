01 • HTML

HTML nima?

HTML — web sahifaning tuzilishini yaratish uchun ishlatiladigan belgilash tili.

Masalan, saytga sarlavha, matn, rasm, tugma, havola, menyu va boshqa elementlarni HTML orqali joylashtiramiz.

index.html 
<!DOCTYPE html>
<html>

<head>
    <title>Mening saytim</title>
</head>

<body>

    <h1>Salom, dunyo!</h1>

    <p>
        Bu mening birinchi web saytim.
    </p>

</body>

</html>

03 • CSS

CSS nima?

CSS — web sahifaning ko‘rinishi va dizaynini boshqarish uchun ishlatiladi.

Rang, shrift, o‘lcham, masofa, animatsiya, grid, flexbox va responsive dizayn CSS orqali yaratiladi.

style.css 
body {
    background: #050807;
    color: white;
    font-family: Arial;
}

h1 {
    color: #00ff88;
    text-align: center;
}

button {
    padding: 12px 20px;
    border-radius: 10px;
    background: #00ff88;
}

05 • FLEXBOX

Flexbox

Flexbox elementlarni gorizontal yoki vertikal tartibda joylashtirishning eng qulay usullaridan biridir.

flex.css 
.container {
    display: flex;

    justify-content: center;
    align-items: center;

    gap: 20px;
}
06 • CSS GRID

Grid

CSS Grid murakkabroq web sahifalarda kartalar va bloklarni ustun-qator ko‘rinishida joylashtirish uchun ishlatiladi.

grid.css 
.cards {
    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;
}
07 • RESPONSIVE

Telefon uchun moslashtirish

        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 35px;
