01 • JAVA NIMA?

Java haqida

Java — keng qo‘llaniladigan, obyektga yo‘naltirilgan dasturlash tili. U desktop dasturlar, Android ilovalar, backend tizimlar va katta korporativ loyihalarda ishlatiladi.

Java'ning muhim xususiyatlaridan biri uning JVM — Java Virtual Machine orqali turli operatsion tizimlarda ishlay olishidir.

Java'ni o‘rganish orqali OOP, ma'lumotlar tuzilmalari va katta dasturlar arxitekturasini tushunish osonlashadi.

03 • VARIABLES

O‘zgaruvchilar

Java'da har bir o‘zgaruvchining ma'lumot turi mavjud.

Masalan: int — butun son, double — kasr son, String — matn, boolean — true yoki false.

Variables.java 
public class Main {

    public static void main(String[] args) {

        String name = "Coder";
        int age = 12;
        double score = 95.5;
        boolean active = true;

        System.out.println(name);
        System.out.println(age);
        System.out.println(score);
        System.out.println(active);

    }

}

10 • CLASS & OBJECT

Birinchi Class

User.java 
class User {

    String name;
    int age;

    User(String name, int age) {

        this.name = name;
        this.age = age;

    }

    void showInfo() {

        System.out.println(
            "Ism: " + name
        );

        System.out.println(
            "Yosh: " + age
        );

    }

}

public class Main {

    public static void main(String[] args) {

        User user =
            new User("Coder", 12);

        user.showInfo();

    }

}
