01 • JAVASCRIPT NIMA?

JavaScript haqida

JavaScript — web sahifalarga interaktivlik va mantiq qo‘shish uchun ishlatiladigan dasturlash tilidir.

HTML saytning tuzilishini, CSS uning ko‘rinishini yaratadi. JavaScript esa saytni "jonlantiradi".

Masalan, tugma bosilganda menyu ochilishi, kalkulyator hisob-kitob qilishi, forma tekshirilishi yoki sahifadagi ma'lumot o‘zgarishi JavaScript orqali amalga oshirilishi mumkin.

03 • VARIABLES

O‘zgaruvchilar

JavaScriptda ma'lumotlarni saqlash uchun o‘zgaruvchilardan foydalanamiz.

Zamonaviy JavaScriptda ko‘pincha let va const ishlatiladi.

variables.js 
let name = "Coder";
let age = 12;

const language = "JavaScript";

console.log(name);
console.log(age);
console.log(language);
