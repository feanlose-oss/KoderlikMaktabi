01 • PHP NIMA?

PHP haqida

PHP — asosan server tomonida ishlaydigan dasturlash tili bo‘lib, dinamik web sahifalar yaratishda ishlatiladi.

PHP HTML bilan birga ishlashi mumkin. Masalan, foydalanuvchi formani yuborganda PHP ma'lumotni qabul qilib, uni qayta ishlashi va database bilan ishlashi mumkin.

PHP ko‘pincha MySQL kabi ma'lumotlar bazalari bilan birga ishlatiladi.

11 • DATABASE

PHP + MySQL

PHP yordamida MySQL ma'lumotlar bazasiga ulanish va undan ma'lumot olish mumkin.

database.php 
<?php

$host = "localhost";
$user = "root";
$password = "";
$database = "codeforge";

$conn = new mysqli(
    $host,
    $user,
    $password,
    $database
);

if ($conn->connect_error) {
    die("Ulanishda xato");
}

echo "Database ulandi!";

?>
12 • PDO

PDO bilan database

pdo.php 
<?php

$pdo = new PDO(
    "mysql:host=localhost;dbname=codeforge",
    "root",
    ""
);

$pdo->setAttribute(
    PDO::ATTR_ERRMODE,
    PDO::ERRMODE_EXCEPTION
);

echo "Ulanish muvaffaqiyatli!";

?>
