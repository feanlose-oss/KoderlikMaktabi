12 • RELATIONS

PRIMARY KEY va FOREIGN KEY

PRIMARY KEY jadvaldagi har bir yozuvni noyob aniqlash uchun ishlatiladi.

FOREIGN KEY esa ikki yoki undan ko‘p jadvallar orasida aloqa o‘rnatishga yordam beradi.

relations.sql 
CREATE TABLE orders (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    product VARCHAR(100),

    FOREIGN KEY (user_id)
    REFERENCES users(id)
);
13 • JOIN

Jadvallarni birlashtirish

join.sql 
SELECT
    users.name,
    orders.product
FROM users

JOIN orders
ON users.id = orders.user_id;
